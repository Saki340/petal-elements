This follows Jetpack Compose Material 3 (`LoadingIndicator`,
`ContainedLoadingIndicator`, `LoadingIndicatorTokens`). The shapes and the
morphing are a TypeScript port of Android's graphics-shapes library
(`RoundedPolygon`, `Morph`) and Compose's `MaterialShapes`, so they match
Compose exactly.

## Usage

Without `value`, the indicator is indeterminate: seven Material shapes (soft
burst, 9-sided cookie, pentagon, pill, sunny, 4-sided cookie, oval) morph into
each other every 650ms on a spring, each morph adding a quarter turn, while
the whole indicator turns once every 4.666 seconds.

content (`ContainedLoadingIndicator`).

### Determinate

With `value` from 0 to 1, a circle morphs into a soft burst as the value grows,
turning half a turn backward.

## Accessibility

The indicator is a `progressbar`, with `aria-valuenow` when determinate. Give
it an `aria-label` that says what is loading.

With `prefers-reduced-motion`, the indeterminate indicator keeps one shape and
only turns. Compose does not change the animation; this is a petal-elements
choice.

## Theming

Loading indicators support [Material theming](../theming/README.md). Every
token of Compose's `LoadingIndicatorTokens` is a `--md-loading-indicator-*`
custom property. The container size also scales the shape.

### Tokens

Token                                            | Default value
------------------------------------------------ | -------------
`--md-loading-indicator-active-indicator-color`  | `--md-sys-color-primary`
`--md-loading-indicator-contained-active-color`  | `--md-sys-color-on-primary-container`
`--md-loading-indicator-contained-container-color` | `--md-sys-color-primary-container`
`--md-loading-indicator-container-width`         | `48px`
`--md-loading-indicator-container-height`        | `48px`
