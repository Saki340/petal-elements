# Security Policy

## Supported versions

Security fixes are applied to the latest published version only.

## Reporting a vulnerability

Report vulnerabilities privately through a
[GitHub security advisory](https://github.com/Saki340/petal-elements/security/advisories/new).

**Please do not disclose security vulnerabilities in public issues.**

If the problem also affects Google's Material Web, please report it to that
project as well, following
[its security policy](https://github.com/material-components/material-web/security/policy).
