Web components · Material 3 Expressive

Expressive Material 3, for the web.

petal-elements brings Material 3 Expressive to plain HTML and any framework: sized buttons that morph when pressed, spring motion, button groups, and the accessible, form-ready components you know from material-web.

Why petal-elements

code

Works anywhere

Standard custom elements built with Lit. Use them in plain HTML, React, Vue, Svelte, Astro or a static site.

accessibility_new

Forms and accessibility

Fields, checkboxes and buttons take part in native <form>s, with keyboard support and screen reader semantics.

palette

Themed with CSS

Every color, shape and type style is a CSS custom property. Light and dark come built in.

straighten

Values from source

Sizes, colors and motion come from the published Material design tokens and Jetpack Compose sources, not from eyeballing.

One color, a whole theme

Pick a source color. The color scheme is generated for light and dark, and every component on this page follows.

Get started

1. Install

npm install petal-elements
content_copy

2. Load the tokens and the components you use

<link rel="stylesheet" href="node_modules/petal-elements/tokens/css/sys.css">
<script type="module">
  import 'petal-elements/button/filled-button.js';
  import 'petal-elements/buttongroup/button-group.js';
</script>

<petal-filled-button size="medium">Save</petal-filled-button>
